
# 🌙 Wallpapers

A curated collection of beautiful wallpapers for developers and wallpaper enthusiasts.

---

## 📸 Preview

This repository contains a collection of high-quality wallpapers in multiple formats (JPEG, JPG, PNG), suitable for various screen resolutions and preferences.

> [!NOTE]
> All wallpapers are optimized for desktop use and come in multiple resolutions to fit different screen sizes.

---

## 🚀 Quick Start

1. **Clone the repository:**

   ```bash
   git clone https://github.com/6hax/wallpapers.git
   ```
2. **Browse wallpapers:**
   Navigate to the `images/wallpapers/` directory to view all available wallpapers.
3. **Download your favorites:**
   Simply download the files you like and set them as your desktop background.

> [!TIP]
> Use PNG for wallpapers with transparency or high-quality needs. JPEG/JPG is better for smaller file sizes.

## 🤝 Contributing

We welcome contributions! Here's how you can help:

### How to Contribute

1. **Fork the repository**
2. **Create a feature branch:**

   ```bash
   git checkout -b feature/amazing-wallpaper
   ```
3. **Add your wallpapers** to `images/wallpapers/`
4. **Follow naming conventions:**

   * Descriptive names
   * Include the format extension (jpg, png, jpeg)
   * Use hyphens/underscores instead of spaces
5. **Commit your changes:**

   ```bash
   git commit -m "Add amazing new wallpaper"
   ```
6. **Push to your branch:**

   ```bash
   git push origin feature/amazing-wallpaper
   ```
7. **Open a Pull Request**

### Contribution Guidelines

> [!IMPORTANT]
> **Image Quality:** Minimum 1920x1080 recommended
> **File Formats:** JPG, JPEG, PNG only
> **File Size:** Keep under 10MB per file
> **Naming:** Clear, descriptive filenames
